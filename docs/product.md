# EVI Product Vision

## Problem

People often know what they want but struggle to convert intentions into consistent action. Traditional productivity tools store tasks; generic chatbots answer questions. EVI aims to connect the two.

## EVI's job

EVI should help a person:

1. Understand what matters to them.
2. Define a meaningful vision.
3. Break the vision into goals.
4. Turn goals into plans.
5. Turn plans into small actions.
6. Build sustainable habits.
7. Reflect and adapt.
8. Remember useful personal context.
9. Execute approved actions through connected tools.

## What makes EVI different

EVI is not intended to be only a chat interface around an LLM.

The core product is an intelligent personal operating layer made of:

- Conversation intelligence
- Personal memory
- Goal intelligence
- Planning
- Habit support
- Reflection
- Permission-aware actions
- Long-term personalization

The LLM is one component of EVI, not the entire product.

## Design principle

EVI should increase the user's capability and agency over time.

A successful EVI user should become more organized, more intentional, and more capable — not more dependent on the AI.
